# Reverse Generative Modeling

Exploring approaches to inverting a trained MNIST classifier — recovering input images from output logits.

## Overview

A feed-forward classifier (`784 → 256 → 128 → 10`) is trained on MNIST. The goal is to invert this mapping: given a logit vector, reconstruct a plausible input image. Two broad approaches are investigated: mathematical inversion and learned inversion.

## Approaches

### Mathematical Inversion (`MathematicalInverse/`)

Inverts the network analytically using the Moore-Penrose pseudoinverse of each weight matrix and the inverse of LeakyReLU (which is itself a scaled LeakyReLU). Because the network is under-determined (784 inputs, 10 outputs), a "square" architecture with equal hidden-layer widths is also trained to explore the effect of layer shape on inversion quality.

Too much information is lost using pseudoinverses resulting in catastrophic forgetting/pure noised images. There is an argument to be made that these pure noise images are 'ground-truth' possibilities resulting from the pseudoinverse minimum norm, but this is unlikely and was not investigated. Could be verified by putting the noise images back through the base network and checking if the logit vectors are the same.

### Learned Inversion (`LearnedInverse/`)

Trains a mirror network (`InverseNN`: `10→128→256→784`) to map logit vectors back to pixel space, supervised by MSE against the original images.

**Self-distillation fine-tuning** improves the model beyond the training distribution by iterating:
1. Sample logit vectors (randomly or from a fitted per-class Gaussian)
2. Generate synthetic images via the current inverse model
3. Re-score with the frozen classifier to obtain "true" logits
4. Fine-tune on the mixed real + synthetic data with an additional KL regularisation term that pushes `classifier(generated_image) ≈ input_logits`

Two sampling strategies were tested: uniform random logits (`finetune_loop_random.py`) and per-class Gaussians fitted to the real logit distribution (`finetune_loop_normal.py`).

### Distribution Analysis (`DistributionAnalysis/`)

Compares the per-digit pixel distributions of real MNIST images against those generated by the inverse models. Each digit's distribution is summarised by its per-pixel mean and standard deviation, visualised as a 4-row grid (mean − std, mean, mean + std, std). The comparison script computes pixel-wise KL divergence (modelling each pixel as a Gaussian) and produces heatmaps and per-digit summary charts.

```bash
# Compare any inverse model against MNIST
python DistributionAnalysis/distribution_comparison.py --model inverse_ffnn_finetuned_normal.pt
```

Key finding: self-distillation fine-tuning reduces average total KL divergence from ~109k (baseline) to ~3.2k (finetuned), primarily by correcting extreme variance collapse on digits 1, 7, 9.

## Workflow

```bash
# 1. Train the base classifier
python mnist_ffnn.py

# 2. Cache the logit datasets
python LearnedInverse/generate_logits.py

# 3. Train the baseline inverse model
python LearnedInverse/reverse_distill.py

# 4. Fit logit distribution stats (needed for normal fine-tuning)
python LearnedInverse/logit_stats.py

# 5. Fine-tune with self-distillation
python LearnedInverse/finetune_loop_normal.py

# 6. Analyse distributions
python DistributionAnalysis/mnist_per_digit_distribution.py
python DistributionAnalysis/inverse_per_digit_distribution.py
python DistributionAnalysis/distribution_comparison.py --model inverse_ffnn_finetuned_normal.pt
```
